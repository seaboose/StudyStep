# Contributing

Use Node.js 24 and the locked pnpm version. Install dependencies, build, and run the checks described in the README before submitting a change.

Keep source references visible, preserve manual workflows without a model, and avoid claiming that self-rated recall demonstrates mastery. Never add real course documents, saved study data, credentials, or model weights to the repository.

For behavioral changes, add a focused test covering the failure and recovery path. For UI changes, check keyboard access, narrow windows, reduced motion, and a complete import-to-practice journey. Describe what changed and how you verified it.
