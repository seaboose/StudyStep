# StudyStep 0.4.0

This Windows consumer version adds the Card Index interface and icon, practice recommendations with editable topic assessments, source follow-up and related reading lists. The app checks followed introductions while open and catches up at startup. It preserves manual import, spaced review, focus history and exports.

StudyStep is the single packaged application. Contributors can use the source development command for experimental local learning agents. The developer workflow uses its own study profile.

## Release checks

Consumer checks cover import, flashcards, quiz outcomes and hints, changing difficulty, correcting topic assessments, persistence, timer and journal export, and source-follow behavior. Windows runs the packaged app. Linux runs the desktop source under a virtual display. A Windows portable ZIP is the supported download. Live Wikipedia discovery and follow checks can be run against that ZIP on a connected Windows machine.

Developer reliability runs separately. It includes bounded model fixtures, cancellation and approval checks, 100 practice-history and topic-edit trajectories, and an isolated seeded defect with before/after repair evidence. Those results measure software behavior; they do not measure learning effectiveness.
